# 棠西村秘闻 · 九章网页版

[进入九章完整版](https://qiyasxsx.github.io/tangxi-seven-seconds-demo/season/) · [单独游玩序章《七秒以后》](https://qiyasxsx.github.io/tangxi-seven-seconds-demo/first-take/)

用手机或电脑打开网页，选择「从头开始」。游戏免登录，进度保存在当前浏览器。

本仓库仅存放网页运行文件，不包含主工程、开发记录或凭据。

字体许可见 `passage/ui/`，声音来源见 `声音来源.json`。

手机采用完整 16:9 横屏构图；竖持时自动旋转画面，横持时正向显示。

配乐：Dark Walk — Kevin MacLeod (incompetech.com)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。[原曲](https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1100468)。本版做循环交叠、音量调整与 AAC 转码。
